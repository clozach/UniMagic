# UniMagic releases

## 1.0.4

- The standalone Mac app and the integrated Tinycast command run the same Unicode palette. The Mac app includes a dedicated picker host and can run independently.
- Restore the category dropdown, on-demand details, automatic paging and keyboard navigation. An immediate repeat of Control–Command–Space closes the picker. After choosing an eligible emoji it opens skin tones.
- The shared Mac picker requires macOS 26+. Upgrade from 1.0.3 with one manual download, then opt into automatic updates if desired. Older Macs retain 1.0.3.

## 1.0.3

- The iPhone picker keeps its momentum across glyph pages during fast flicks. Slow drags keep their precision.
- Browsing loads glyphs around the visible area, and returning from Details restores the selected Recents entry.

## 1.0.2

- A native Mac menu-bar picker, available without Tinycast, with the existing Unicode search, learning, browsing and glyph details.
- A standalone iPhone app and keyboard, preserving separate native histories and no Full Access requirement.
- Optional Tinycast access to the same Mac library, with migration from the retired Obsidian plugin.
- Clear opt-in updates, easy opt-out, category visibility settings and visible installed versions.
- Verified paired-Mac iPhone updates and signing renewal, with data preservation and recovery.
- A reusable maintainer Publish workflow and portable public source with third-party notices.
