# UniMagic releases

## 1.0.2

- A native Mac menu-bar picker, available without Tinycast, with the existing Unicode search, learning, browsing and glyph details.
- A standalone iPhone app and keyboard, preserving separate native histories and no Full Access requirement.
- Optional Tinycast access to the same Mac library, with migration from the retired Obsidian plugin.
- Clear opt-in updates, easy opt-out, category visibility settings and visible installed versions.
- Verified paired-Mac iPhone updates and signing renewal, with data preservation and recovery.
- A reusable maintainer Publish workflow and portable public source with third-party notices.
