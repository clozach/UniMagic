# Emotif built-in data

`emotif-builtins.json` preserves the built-in names, shortnames, aliases and keywords used by Chris Lozac'h's 2016 Emotif application. It is build-time vocabulary data, not a copy of personal learned words or usage history.

The Emotif source identifies its built-in search strings as sourced from EmojiOne. EmojiOne's archived 2.x license classifies JSON and other non-artwork material under MIT; its separate artwork license is not used here. No EmojiOne PNG, SVG or font artwork is bundled.

Upstream license: https://github.com/EmojiTwo/EmojiOne-archive/blob/master/LICENSE.md

The unmodified upstream notice is retained as `licenses/EmojiOne-LICENSE.md`. UniMagic's normalization and learning implementation are original MIT-licensed code. The inherited keyword strings are kept intact.
