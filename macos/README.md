# Native macOS host

Build from the source root with `node esbuild.tinycast.mjs` (optional command), then `node macos/build.mjs`. The app is written to `macos/build/UniMagic.app`; `UNIMAGIC_BUILD_DIR`, `BUILD_VERSION`, `BUILD_NUMBER`, and `SIGN_IDENTITY` configure output/signing. The build pins the bundled runtime to Node22.21.1. Run under that version or set `UNIMAGIC_NODE` to its executable; any other runtime fails before changing the existing build. The build uses that Node distribution and requires its adjacent LICENSE. Its self-contained runtime and complete upstream license are copied into the signed app; `otool -L` must show only system dependencies. No Xcode GUI or third-party runtime installation is needed to run the result.

The native menu-bar app registers Control-Command-Space. Release Tinycast's old binding before enabling the production app. Return inserts, Command-Return reverses Keep open for one pick, Shift-Command-C copies, Control-H/J/K/L moves through glyphs, Tab opens details, and Escape closes details then the picker. Insertion copies the exact string and sends Command-V to the preceding app; macOS Accessibility permission is required. Refusal preserves the glyph on the clipboard. Settings offers category visibility, real shared release controls, a reserved version/build corner, and the bundled optional Tinycast folder importer.

Both hosts default to `~/Library/Application Support/UniMagic/Library/{data.json,personalization-v1.json}`. First launch discovers a legacy store through Obsidian’s registered-vault list and copies its existing files byte-for-byte, preserves originals, and never overwrites an existing destination. `UNIMAGIC_LEGACY_DATA` can select a legacy `data.json`; its adjacent personalization file migrates with it. Both files are validated before either migration write. Settings/unknown fields survive learning writes. Exclusive directory locks serialize native/Tinycast read-modify-write operations; a busy or abandoned lock reports an error and preserves data. Recover an abandoned lock only after confirming both apps are stopped. The old Obsidian plugin must be retired only after migration readback. There is no new cross-device sync.

Run `pnpm exec vitest run tests/*.test.ts`, `pnpm exec tsc --noEmit`, `node macos/verify-bridge.mjs`, and `node macos/verify-native.mjs`. The bridge check uses temporary synthetic stores to exercise the actual bundled desktop engine. `UNIMAGIC_FIXTURE=1 UNIMAGIC_LIBRARY=/tmp/unique-library` disables global registration and paste. Add `UNIMAGIC_CAPTURE=/tmp/capture.png`, `UNIMAGIC_CAPTURE_QUERY=arrow`, `UNIMAGIC_APPEARANCE=light|dark`, and optionally `UNIMAGIC_CAPTURE_DETAIL=1` or `UNIMAGIC_CAPTURE_SETTINGS=1` for native snapshots. Never use personal stores for fixtures. New installations start without private screenshot history; migrated existing history is retained.
